Siskon Packet Racer

Race through network office and wreak havoc while carrying network packets. Watch out for angry Sysadmin and his firewall of death!
https://ultimatevois.github.io/siskon-packet-racer/

Controls:
Key	Action
A / Left Arrow	Accelerate
D / Right Arrow	Reverse
Space	Jump
Esc	Pause


The development source repository is maintained separately.
